# Portfolio — Roberta Vinciguerra

Sito portfolio statico realizzato con HTML5, Bootstrap CSS, CSS Grid/Flexbox e Sass.

## Struttura

- `index.html`: presentazione, progetti, competenze e personalità
- `cv.html`: curriculum completo in formato HTML
- `contact.html`: pagina contatti con form
- `scss/main.scss`: sorgente Sass
- `css/main.css`: foglio CSS compilato

## Pubblicazione con GitHub Pages

1. Crea un account gratuito su GitHub.
2. Crea un repository pubblico chiamato `portfolio-roberta`.
3. Carica tutti i file mantenendo la struttura delle cartelle.
4. Apri **Settings → Pages**.
5. In **Build and deployment**, scegli **Deploy from a branch**.
6. Seleziona `main` e la cartella `/root`, quindi salva.

GitHub mostrerà l’indirizzo pubblico dopo pochi minuti.
